# BLADE STUDIO - concept redesign

Демонстрационная концепция сайта. Это не официальный сайт салона.

## Публикация через GitHub Pages

1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите `index.html` в корень репозитория.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. Через некоторое время GitHub Pages покажет публичную ссылку на сайт.

Шрифты и фотографии загружаются из внешних источников, поэтому для корректного отображения нужен интернет.
